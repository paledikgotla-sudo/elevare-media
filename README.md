# Elevare Media Website

Responsive static website for Elevare Media.

## Before publishing
- Replace portfolio concept panels with approved real work or retain the concept labels.
- Add your own video URLs to the `videoLinks` array in `script.js`.
- Confirm pricing, package scope and revision limits before accepting clients.
- The enquiry form opens the visitor's email app; it does not store submissions.

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, select Deploy from a branch.
3. Choose `main` and `/(root)`, then Save.
4. Wait for the Pages URL to appear on that screen.
